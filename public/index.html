What comes with it

  • Node.js with zero dependencies: no node_modules, no supply chain to poison.
  • Strict security headers on every response, including errors and 304s.
  • Passwordless accounts: a one-time code by e-mail, sessions stored only as hashes.
  • Errors with a code and a log reference, never a stack trace.
  • Download-my-data and delete-my-account, for LGPD and GDPR.
  • CI with tests, secret scanning, a header check and an OWASP ZAP scan.
